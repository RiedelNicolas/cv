# CV/Resumee

A simple web-based CV/Resume built using [Preact](https://preactjs.com/).

Now with a little blog, rendering .md files

The PDF version lives in `cv.typ` and is compiled with
[Typst](https://typst.app) into `src/public/Nicolas-Riedel-CV.pdf`:

```
cd src && yarn cv    # needs: brew install typst
```
